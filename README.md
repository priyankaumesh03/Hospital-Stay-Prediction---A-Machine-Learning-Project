# Hospital Stay Prediction – Machine Learning Project

## 📌 Project Overview

Hospital Stay Prediction is a Machine Learning project that predicts the
category of a patient's hospital stay based on healthcare and patient-related
information.

The project uses a multiclass classification approach to classify hospital
stays into 11 different categories.

## 🎯 Problem Statement

Predict the expected hospital stay category of a patient using features such
as ward, department, type of admission, severity of illness, age, number of
visitors, extra rooms available, bed grade, and admission deposit.

## 🤖 Machine Learning Models

The following classification algorithms were compared:

- Decision Tree
- Random Forest
- Gradient Boosting
- Balanced Random Forest

The models were evaluated using:

- Accuracy
- Macro F1-Score
- Weighted F1-Score
- Confusion Matrix

## 🏆 Final Model

Balanced Random Forest was selected as the final model based on its improved
Macro F1-Score across the 11 hospital stay categories.
